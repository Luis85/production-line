# The Forge 0.1.0

The first portable release of The Forge, a terminal companion for AI-assisted projects and Obsidian-compatible knowledge work.

## Install and start a project

Requires Node 22.12 or newer, curl and tar. No npm install is needed to run the app.

```sh
curl -fL https://github.com/Luis85/agent-cli/releases/download/v0.1.0/install-forge.mjs -o install-forge.mjs
node install-forge.mjs --version 0.1.0 --workspace ./my-workspace
cd my-workspace
node bin/forge.js project create my-project --dry-run
node bin/forge.js project create my-project
node bin/forge.js project open my-project
node bin/forge.js project current --json
```

The installer downloads `forge-0.1.0.tar.gz` and its SHA-256 checksum, verifies the archive and executable version, installs generic workspace defaults, and runs setup. It refuses to replace an existing `bin/`. Keep the installer outside the destination workspace. For agent instructions, offline installation and platform examples, see the [installation guide](https://github.com/Luis85/agent-cli/blob/v0.1.0/src/the-forge/docs/how-to/install.md).

## Self-update

The app can upgrade itself with `update check` and a reviewed `update apply --release-version <version> --if-match <revision> --dry-run`, followed by the same command without `--dry-run`. It verifies the GitHub release checksum and updates owned assets with revision guards while preserving configuration, selected project, plugins, templates and custom webviews. See [app updates](https://github.com/Luis85/agent-cli/blob/v0.1.0/src/the-forge/docs/reference/updates.md).

## Included

- Self-contained CLI and localhost server, with the read-only Vue admin view.
- Guarded Markdown, Canvas, Bases and source-file operations, revision checks, previews and JSON responses.
- Managed TypeScript projects, Vue/Nuxt UI prototypes, code and form generators, declarative UI and Storybook workflows.
- Backlog planning, agent definitions, Claude Code integration, plugin contracts and packaged agent skills.
- Browser screenshots and explicit tutorial replay with illustrated documentation.
- Packaged reference documentation, SDK declarations and third-party license notices.

Chromium is a separate optional download: run `node bin/forge.js browser install` before browser capture, or provide an existing browser executable. Generated projects own their dependencies and require their own `npm ci` and checks. Authenticated Azure DevOps and Claude integrations require user configuration. Plugins execute trusted Node code.

The release workflow checks the application, tests this exact archive on Linux, macOS and Windows with Node 22.12 and 24, downloads the uploaded draft assets and repeats the fresh-workspace smoke test before making the release public.
