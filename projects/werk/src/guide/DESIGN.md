# System guide surface

Mode: Read. This standalone guide explains Factory, sub-factories, production
lines, orchestrators, workers and tasks, with a local system-definition composer.
It is served at `/guide` by
Factory and orchestrator; the runtime links open it separately so unsent work and
memory-only credentials stay in the original tab.

Use the operational palette, system typography, visible keyboard focus and spacing
scale recorded in the project DESIGN. The reading layout adds a narrow section
navigation column on desktop and wraps that navigation above the text on mobile.
Comparison tables scroll inside labeled keyboard-focusable regions. Interactive
topology and deployment controls require at least 44px targets and native keyboard
activation; selected state and updated explanatory text are announced semantically.

The shared canvas topology offers orthographic 3D and 2D views. It is illustrative,
never a live inventory. Native entity buttons select explanatory facts and next
actions in the inspector. Camera buttons rotate, zoom and reset; touch gestures
and native keyboard scrolling pan the diagram. The inspector moves below the
diagram at 1100px and becomes a single column at 760px and below. Task-lifecycle
buttons return to the relevant entity explanation; they do not execute tasks.

Deployment controls select native or Docker examples. The local composer previews
and downloads a `system.yaml` declaring a Factory, one independent line and one to
eight worker processes using mock execution. It checks required fields, identifier
constraints, distinct service ports and the consecutive worker-status port range.
The operator must validate the downloaded file with `system plan` before starting
it in a new state directory. No guide action starts a service, submits a task,
applies configuration, migrates existing state or transmits a credential.
Credentials are generated by the launcher, never by this form. Native and Docker
commands must match the supported launcher contract. The composer does not change
the native launcher's default two independent lines.

Keep operational management in Factory, line tasks and worker details in the
orchestrator, and process status on the worker itself. Do not embed the guide as
another dashboard or duplicate the simulated concept demo here. The return link
returns to the serving runtime; hide it when the standalone file has no runtime.

Verification targets: desktop 1440px and mobile 390px/320px browser inspection,
keyboard entity/deployment switching, touch and keyboard diagram panning,
comparison-table scrolling, no whole-page overflow and schema validation of the
actual downloaded YAML. Record completed checks in dated evidence; these targets
are not a claim of final review acceptance.
