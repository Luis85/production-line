The release documentation follows [Diátaxis](https://diataxis.fr/): tutorials teach
one complete flow, how-to guides solve operating tasks, reference describes exact
contracts, and explanations describe the system and its limits.

A running Factory or orchestrator also serves `/guide`: a standalone public guide
with no API calls or administrative actions. It explains the model; authenticated
service webviews show current runtime state.

This is the installed-runtime documentation. Source development, original concept
material, implementation backlog and dated review evidence belong to the source
checkout and are not prerequisites for running this release.
