# Start Prompt

The retained start prompt describes the accepted outcome, criteria, pinned baseline and approved file/tool scope, selected execution profile, checks, dependency evidence and bounded runtime/repair allowance. Its saved dispatch identity links it to the Feature Request revision and delivery run.

It contains no provider credentials and cannot expand machine grants. A resumed provider invocation receives worker-owned context and retained candidate findings; an uncertain earlier invocation must be reconciled before starting another.
