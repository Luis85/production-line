# Canonical project intake and queue

Webview, CLI and Markdown target one stable project-scoped Feature Request identity. Project/template selection, default Low priority, readiness findings and shared commit/push/claim handoff must agree.

Exit: duplicate retries create one request; changed command payloads conflict; invalid drafts preserve user text; conflicting source identity blocks new dispatch. Kanban and CLI show the persisted next action rather than an invented success.

See [intake process](../../processes/Worker%20Intake.md) and [request gates](../../reference/request-gates.md).
