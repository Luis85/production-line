# Worker intake to published release

Deliver the primary standalone workflow from a registered project's Feature Request through Claude execution, independent verification, current-candidate human review, verified merge, exact-source build and a published GitHub Release.

The selected live acceptance target is native Windows with Claude Code CLI and GitHub Release assets. Keep this feature Active until its [acceptance ledger](../../reports/worker-release-workflow-acceptance.md) has actual live evidence. Automated source/fixture checks and native/live qualification are separate requirements.

See the [workflow contract](../../reference/worker-release-workflow.md) and [operating guide](../../how-to/deliver-worker-release.md). Existing imported P0 items retain their distinct leased line/orchestrator scope; reuse does not blanket-complete them.
