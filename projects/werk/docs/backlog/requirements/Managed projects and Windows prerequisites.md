# Managed projects and Windows prerequisites

Register a remote project under the worker home or explicitly adopt an existing checkout. Preserve durable operation identity, safe clone/retry/restart behavior, approved policy boundaries, project/intake identity and developer files/index.

Exit: real Git fixtures cover clone/adopt/conflict/recovery, tool diagnostics expose unavailable prerequisites without credentials, and native Windows setup is qualified separately. Registration does not approve policy or invoke unfinished setup automatically.

See [managed projects](../../reference/worker-release-workflow.md#managed-projects) and the [acceptance ledger](../../reports/worker-release-workflow-acceptance.md).
